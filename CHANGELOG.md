# Changelog

All notable changes are documented here. The project follows semantic versioning.

## 0.1.1 — 2026-08-28

- Redact sensitive query-string values in changed-URL evidence before JSON and Markdown reports are rendered.
- Cover source and target query-secret redaction through the public CLI in both report formats.

## 0.1.0 — 2026-08-27

- First local migration verifier for Postman v2.1 to Bruno or Hoppscotch.
- Markdown and stable JSON reports with secret-safe variable metadata.
- Optional environment comparison and CI failure thresholds.
- Local browser demo and blueprint documentation site.
