Local by design

P–01 Effective 28 August 2026

Understand what stays on your device

Files stay local

The CLI reads only the file paths you provide. The browser demo keeps selected JSON in memory.

Neither tool uploads files, sends API requests, or sends reports to us.

We collect no product data

This version has no analytics, cookies, accounts, telemetry, crash reports, or server-side storage.

The static host may keep short-lived infrastructure access logs.

Reports remove secret values

Reports keep names, paths, methods, scopes, and other structural details. They never include variable values or headers.

Reports replace URL credentials and sensitive query values with redaction markers.

The public shell works offline

A service worker caches the public site after your first visit. It never caches files selected in the browser demo.

Clear this site's browser data to remove the public cache.

Report a privacy problem

Open an issue in the project repository (opens external site). Never attach a real collection or secret.
