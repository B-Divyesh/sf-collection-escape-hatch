B–02 Three steps

Compare a migration the same way every time

One read-only comparison creates a report your team can review.

  1. 01

    Choose the source and target exports

    Use the original Postman v2.1 export and the Bruno or Hoppscotch export.

  2. 02

    Compare the exported structure

    Requests match by folder path and name. The CLI compares fields, scripts, examples, variables, and body bytes.

  3. 03

    Save the comparison report

    Review Markdown with your team. Use stable JSON and exit codes to compare saved migration examples in CI.

E–05 Clear limits

Compare structure, not live behavior

The CLI does not send requests or run scripts. It cannot prove that both API clients behave the same.

Reports remove variable values, headers, URL credentials, and sensitive query values before rendering.

F–06 Build from source

Install one local binary

Clone the repository, then install the CLI with Cargo. No account is required.

source installread only
